# Technical Stack

- **Frontend**: React 18, TypeScript, Vite 5, Tailwind CSS v3, Framer Motion, Recharts
- **API (Impl 29+)**: Express 5 in sibling `backend/`. Staff auth (Impl 31 + 48): httpOnly JWT cookie, bcrypt, `/api/staff/*` (setup, auth-options, forgot/reset, optional TOTP, env-gated SSO). Catalog CRUD (Impl 32): `/api/authors|genres|webtoons|episodes`. Coin packages (Impl 44): `/api/coin-packages`. Comments moderation (Impl 45): `/api/comments` (soft-delete). Staff notifications inbox (Impl 46): `/api/notifications` (hard-delete). Reader broadcasts (Impl 51): `/api/reader-broadcasts` (website service delivers). Platform settings (Impl 47): `/api/settings` (four portal-safe fields). Admin SPA (Impl 33): mock by default; `VITE_USE_MOCK_API=false` uses cookie + REST. Media (Impl 34–35, 41): `/api/media`; local disk when R2 env is fake/missing; Cloudflare R2 `ObjectStore` when real R2 env is set. Live R2 smoke + one published title is Impl 50 (URL shape `{R2_PUBLIC_BASE_URL}/admin/{key}`, not `/uploads/`). Live join desk is Impl 52. CORS/cookie from env (Impl 42): `CORS_ORIGINS` (default `http://localhost:5173`), `COOKIE_SAMESITE` / `COOKIE_SECURE`. Invite mail (Impl 43): in-repo HTML via Brevo when real env is set; `fake`/missing skips send. SPA Library/Picker use REST only when the mock flag is `false`. No Cloudinary SDK.
- **Database (Impl 30+)**: PostgreSQL + Prisma 6. `DATABASE_URL` in `backend/.env` only (never `VITE_*`). See [`conventions/backend-workspace.md`](conventions/backend-workspace.md) and [ADR 003](decisions/003-postgresql-prisma.md).
- **Shared Package**: `@softgate/shared` containing shared types and mock data layers
- **Brand tokens**: Logo-aligned teal `primary-*` (`#64c8c8` / `#0e9494`) + magenta `burst-*` (`#e63264`) — see `wiki/conventions/brand-color-tokens.md`
- **Testing**: Vitest for unit tests, Playwright for E2E integration tests
