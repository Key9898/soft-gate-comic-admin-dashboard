# Technical Stack

- **Frontend**: React 18, TypeScript, Vite 5, Tailwind CSS v3, Framer Motion, Recharts
- **API (Impl 29+)**: Express 5 in sibling `backend/`. Staff auth (Impl 31 + 48): httpOnly JWT cookie, bcrypt, `/api/staff/*` (setup, auth-options, forgot/reset, optional TOTP, env-gated SSO). Catalog CRUD (Impl 32): `/api/authors|genres|webtoons|episodes`. Coin packages (Impl 44): `/api/coin-packages`. Comments moderation (Impl 53): `/api/comments` (portal `ReaderComment`; reported queue; hard-delete). Reader users (Impl 54): `/api/users` (portal `ReaderUser`; profile PATCH; hard-delete; wallet read-only). Staff notifications inbox (Impl 46): `/api/notifications` (hard-delete). Reader broadcasts (Impl 51): `/api/reader-broadcasts` (website service delivers). Platform settings (Impl 47): `/api/settings` (four portal-safe fields). About history (Impl 59): `/api/about/history` (photo first-of-year; write = super_admin/admin). About team (Impl 60): `/api/about/team` (members + meta; photo on every member; write = super_admin/admin). Press CMS (Impl 63): staff `/api/press` (meta + news + stills; write = super_admin/admin; page-local `/press` desk). FAQ + Cookie Policy CMS (Impl 66): staff `/api/faq` and `/api/cookies` (write = super_admin/admin; page-local `/faq` `/cookies`; first GET seeds FAQ `q1`–`q20` and 16 cookie rows). Admin SPA (Impl 33): mock by default; `VITE_USE_MOCK_API=false` uses cookie + REST. Media (Impl 34–35, 41, 56): `/api/media`; local disk when R2 env is fake/missing; Cloudflare R2 `ObjectStore` when real R2 env is set; live JPEG/PNG/still WebP ingest stores same-pixel WebP. Live R2 smoke + one published title is Impl 50 (URL shape `{R2_PUBLIC_BASE_URL}/admin/{key}`, not `/uploads/`). Live join desk is Impl 52. Episode add/edit is `/episodes/new` and `/episodes/:id/edit` (Impl 55); JPEG/PNG pages go through `/api/media` (live URL is `.webp`). Webtoon add/edit is `/webtoons/new` and `/webtoons/:id/edit` (Impl 58); cover from Media. About history desk is `/about` (Impl 59); Team section under History is Impl 60; reader `/about` unchanged until website 205–207. Press desk is `/press` (Impl 63); reader `/press` consumes website `GET /api/press` (website 211). FAQ desk is `/faq` and Cookies desk is `/cookies` (Impl 66); reader `/faq` `/cookies` can show saved copy when the portal persist is on (website 213). Catalog load (Impl 61): satellite GET 500 does not wipe catalog. Live business (Impl 64): Dashboard/Analytics/Revenue chart and transaction slices stay empty on the catalog API (not portal money); mock desk keeps demo series. Live Reports / Activity Log (Impl 65): reports and activity-log seeds stay empty on the catalog API; Reports caption **Not wired on live**; Activity Log caption **This session only**. CORS/cookie from env (Impl 42): `CORS_ORIGINS` (default `http://localhost:5173`), `COOKIE_SAMESITE` / `COOKIE_SECURE`. Invite mail (Impl 43): in-repo HTML via Brevo when real env is set; `fake`/missing skips send. SPA Library/Picker use REST only when the mock flag is `false`. No Cloudinary SDK.
- **Database (Impl 30+)**: PostgreSQL + Prisma 6. `DATABASE_URL` in `backend/.env` only (never `VITE_*`). See [`conventions/backend-workspace.md`](conventions/backend-workspace.md) and [ADR 003](decisions/003-postgresql-prisma.md).
- **Shared Package**: `@softgate/shared` containing shared types and mock data layers
- **Brand tokens**: Logo-aligned teal `primary-*` (`#64c8c8` / `#0e9494`) + magenta `burst-*` (`#e63264`) — see `wiki/conventions/brand-color-tokens.md`
- **Testing**: Vitest for unit tests, Playwright for E2E integration tests
