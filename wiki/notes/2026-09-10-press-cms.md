# Impl 63 — Press CMS (Admin writes, website `/press` reads)

Admin owns Press content in shared Postgres (About-class CMS). The website public API reads those tables and `/press` renders them, keeping today’s chrome. This fills the previously reserved Impl 63 slot; Impl 64 (live business empty) stays.

## Split

- **Admin** = content + file URLs (`/press` desk, staff `/api/press`).
- **Website** = Press chrome (TOC, layout, Copy control, JSON-LD shape) + `GET /api/press`.
- Not a page builder. Not Media ZIP ingest. Not site theme tokens. Repos stay separate.

Pipe: Admin desk → Admin Express staff `/api/press` → shared Postgres → website `GET /api/press` → portal `/press`. On mock or fetch fail, portal keeps `t('press.*')`.
